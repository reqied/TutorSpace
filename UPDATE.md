# Обновление рабочей Docker-версии

Обновление добавляет уроки и домашки с несколькими заданиями, ответы/решения для репетитора, наборы карточек и блоки кода.

## Порядок обновления на Windows

1. Распакуй содержимое папки `tutor-space` из нового архива поверх **той же** рабочей папки `D:\tutor-space`. Подтверди замену исходников. Файла `.env` в архиве нет: твой `.env` нужно сохранить. Также сохрани собственные изменения конфигурации, если они есть. Название рабочей папки не меняй: от него зависит имя Docker Compose-проекта и используемых томов.
2. В PowerShell из `D:\tutor-space` сделай резервную копию:

```powershell
powershell -ExecutionPolicy Bypass -File .\backup.ps1
```

Скрипт на время остановит API и web, скопирует базу, материалы, ключи входа и `.env` в `backups\дата-время`, затем снова запустит контейнеры. Дождись успешного сообщения о копии. Дамп копируется как файл через `docker cp`, без перенаправления бинарного вывода в Windows PowerShell.

3. Собери и запусти обновление:

```powershell
docker compose up -d --build
docker compose ps -a
docker compose logs --tail=80 api
```

В Dockerfile уже стоят рабочие образы `dotnet/sdk:10.0-alpine` и `dotnet/aspnet:10.0-alpine`. `.NET 10` сохраняется. `init.ps1` повторно запускать не нужно.

4. Открой http://localhost:8080 и обнови страницу через Ctrl+Shift+R. Логин и пароль прежние.

Не выполняй `docker compose down -v`: эта команда удаляет тома с данными.

## Что происходит с базой

При первом старте обновлённого API выполняется транзакционное обновление схемы №2. Добавляются таблицы задач, ответов на задачи и карточек, а также ссылка занятия на материал урока. Прежнее условие и правильный ответ каждого материала переносятся в «Задание 1». Старые ответы учеников, комментарии и статусы переносятся в ответы на это задание. Учётки, файлы, расписание, оплаты и доски остаются.

Завершённое обновление записывается в `SchemaVersions`. Повторный запуск не дублирует задачи. При ошибке транзакция откатывается; пришли логи API, не удаляя базу. Обновление проверено на базе, созданной предыдущей сборкой приложения, через PostgreSQL-совместимый PGlite; реальный Docker Desktop/PostgreSQL 17 в среде подготовки недоступен.

После успешного обновления просто запустить старый образ недостаточно для полноценного отката: формат материалов изменился. Для отката потребуется восстановить согласованную резервную копию базы и файлов вместе с прежней версией приложения.

## Как пользоваться новыми функциями

- **Библиотека → Создать материал**: задай название, раздел и тип. Введение/теория — общий текст; ниже добавляй задания. У каждого задания отдельные название, условие, правильный ответ и подробное решение. Автопроверка включается отдельно: эталонный ответ можно хранить и для ручной проверки.
- Кнопки вверх/вниз меняют порядок. «Скопировать задание из библиотеки» добавляет независимую копию задания с ответом и решением в другой урок или домашку. Один готовый материал можно назначать разным ученикам.
- В просмотре задания раскрывай **«Ответ и решение · только репетитору»**. Эти поля исключаются из ответа API ученика. Не помещай секретное решение в общее условие или введение.
- В расписании при создании/редактировании занятия выбери **«Материал урока»**. У тебя и ученика появится «Открыть урок». Для сдачи ответов назначь этот материал через «Назначить», затем ученик работает в разделе «Задания».
- Ответ и проверка теперь отдельные для каждой задачи. Когда все задачи решены/приняты, завершается всё назначение. Ручная проверка доступна под ответом на соответствующую задачу.
- **Карточки → Создать набор**: укажи название, раздел, лицевую сторону и оборот карточек. Назначай набор ученикам прямо в карточке набора. Ученик переворачивает карточку, выбирает «Знаю»/«Повторить». Результат хранится на сервере; репетитор видит прогресс по ученикам. Это обычное повторение, не алгоритм интервального расписания.
- В редакторах есть выбор языка и **«Вставить код»**. Выделенный текст помещается в блок кода; без выделения вставится пример. Есть предпросмотр. Код поддерживается в теории, условиях, решениях, ответах ученика и карточках. Он отображается с сохранением отступов и копируется; выполнение кода не реализовано.

Пример блока:

````text
```python
for i in range(5):
    print(i)
```
````

Формулы по-прежнему пишутся через `$...$` и `$$...$$`. Формулы и ссылки внутри блоков кода остаются обычным текстом кода.

## Редактирование назначенных материалов

Материал общий для всех учеников, которым он назначен: его редактирование меняет текущую версию у всех. Для независимой версии создай новый материал и скопируй нужные задания. Удаление задания/карточки скрывает его из текущего материала/набора, но старые ответы и прогресс остаются в базе. История удалённых заданий пока не вынесена в отдельный экран. Сохранённые результаты не переоцениваются автоматически при изменении эталонного ответа.
