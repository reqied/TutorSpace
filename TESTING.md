# Проверки версии 2

Backend собран .NET SDK 10; frontend проверен TypeScript и собран Vite. Выполнены реальные HTTP и WebSocket запросы к ASP.NET Core API с Npgsql и PostgreSQL-движком PGlite через PostgreSQL wire protocol.

1. Запущена предыдущая сборка API, созданы ученики, материал, назначение, ответы, файл, занятие и доска. Прежний tests/integration.mjs прошёл.
2. На той же базе запущена новая сборка. Проверено сохранение учёток, условий, эталонных ответов, ответов учеников, комментариев и статусов после обновления схемы.
3. Прежний тест API повторно прошёл на новой версии: роли, изоляция учеников, проверка ответов, файлы, расписание/оплата, запись доски, конфликт версий, SignalR и запрет чужого Origin.
4. tests/learning-v2.mjs проверяет несколько задач, доступ через запланированный урок, сдачу/проверку по задачам, сокрытие ответов и решений, принадлежность задачи материалу, перестановку/архивацию с сохранением ответов, назначение карточек, изоляцию прогресса и повторную оценку карточки.
5. Повторный старт не дублирует задачи или запись обновления схемы.

Docker Desktop и PostgreSQL 17 в контейнере здесь недоступны. Полная Docker-сборка, браузерные клики/визуальная проверка и отправка в реальные Telegram/VK не проверялись. Alpine-вариант образов сохранён по успешному запуску предыдущей версии на компьютере пользователя.

## Повторение API-тестов

Нужны Node.js 24, npm ci --prefix frontend и отдельный тестовый экземпляр приложения. Тесты создают записи; не запускай на рабочей базе.

```powershell
$env:TEST_URL="http://localhost:8080"
$env:TUTOR_EMAIL="test-tutor@example.ru"
$env:TUTOR_PASSWORD="test-tutor-password"
node tests/integration.mjs
node tests/learning-v2.mjs
```

Дополнительно прошёл тест content-render.tsx: код экранируется, HTML внутри него не становится разметкой, формулы в блоках кода не обрабатываются KaTeX, формулы вне кода и встроенный код отображаются. Release publish выполнен; файл Schema/002.sql присутствует в готовом серверном приложении.
